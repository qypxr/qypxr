# Привет! 👋

Пишу десктопные программы на **C++** (Windows, Dear ImGui + DirectX 11).
Люблю, когда у программы аккуратный интерфейс и она делает одну вещь хорошо.

## 🛠 Мои проекты

### 🎬 [QYPXR METHOD](https://github.com/qypxr/QYPXR_METHOD)
Оптимизатор видео для TikTok. Перетаскиваешь MP4/MOV, задаёшь целевой FPS (по умолчанию 400), нажимаешь кнопку, и программа перестраивает структуру файла без перекодирования.
`C++` · `Dear ImGui` · `DirectX 11` · `Windows`

### ⬇️ [Smart Grabber](https://github.com/qypxr/Smart-Grabber)
Программа с графическим интерфейсом для скачивания видео с YouTube в высоком качестве, вплоть до 4K. Использует yt-dlp и FFmpeg, которые докачиваются при первом запуске.
`C++` · `Dear ImGui` · `yt-dlp` · `FFmpeg` · `Windows`
