## 🌌 Обо мне

Пишу десктопные программы на **C++** для Windows. Люблю, когда у программы аккуратный интерфейс и она делает одну вещь хорошо.

## ⚡ Проекты

| Проект | Что делает | Стек |
| :--- | :--- | :--- |
| **[QYPXR METHOD](https://github.com/qypxr/QYPXR_METHOD)** | Оптимизатор видео для TikTok: перетаскиваешь MP4/MOV, задаёшь целевой FPS, и программа перестраивает структуру файла без перекодирования | `C++17` `Dear ImGui` `DirectX 11` |
| **[Smart Grabber](https://github.com/qypxr/Smart-Grabber)** | Скачивание видео с YouTube в высоком качестве, вплоть до 4K, с чистым интерфейсом. Работает на базе yt-dlp и FFmpeg | `C++` `FFmpeg` `yt-dlp` |
